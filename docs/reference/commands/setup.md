# Commands: setup

## `setup.install` (modifies state)

Since 0.1.4.

Install what an export needs: the Android JDK + SDK, the players of other platforms, CMake, the AppImage tools, sokol-shdc, the VS Code debugger extension, ffmpeg (or open Xcode's App Store page).

Downloads and installs one component into $FACTORIA_HOME (default ~/.factoria) and returns {component, changed, steps[], paths, nextSteps[], warnings[], seconds}; every step says whether it was installed or skipped because it was already there. It downloads hundreds of megabytes (setup.status says how many: installSizeMb) and can take minutes: ask the user before calling it. `android`: JDK 21 (Eclipse Temurin) and the Android SDK command-line tools, platform-tools, platform 36 and build-tools 35.0.0 (the SDK found on this computer is reused, except Unity Hub's), saved in ~/.factoria/export.json so `project.export` finds them. It REFUSES with error code `license_required` until acceptLicenses is true: the Android SDK license is a legal agreement between the user and Google, so show the user the text from setup.status (components[].licenses[].text) and set acceptLicenses ONLY after they have read it and said yes; never set it on your own. `players`: the factoria_player of the other desktop OSes plus the prebuilt mobile libraries, for exports to other platforms without building anything; from the GitHub release of this factoria's version (a development build ahead of the last release takes the newest release's players and warns that their build fingerprint will not match, so an export needs allowPlayerMismatch; code `no_release` only when even the newest release cannot be read); platforms narrows it (windows, linux, macos, mobile, web). `webplayer`: builds the web player from the checkout this factoria was built from (CMake preset web-release) into build/web-release/player, where the web export looks first; uses an Emscripten SDK it finds ($EMSDK, emcc on PATH, .cache/emsdk, ~/emsdk) or fetches the pinned one (6.0.10, about 1 GB) into the checkout's .cache/emsdk; takes several minutes, so ask the user first; skipped when the player there is of this factoria's build. `cmake`: CMake 3.31 from Kitware (macOS only, for iOS exports) unless 3.24+ is found; force installs it anyway. `xcode` (macOS): cannot be installed by a program: it opens Xcode's App Store page and returns the steps the user must do (some need their password). `appimage` (Linux x86_64): appimagetool 1.9.1 and the AppImage runtime from github.com/AppImage, about 16 MB, into $FACTORIA_HOME/tools/appimage. `shaders`: the pinned sokol-shdc (github.com/floooh/sokol-tools-bin, 8-12 MB depending on the computer) into $FACTORIA_HOME/tools/sokol-shdc/<commit>/, for source builds and editor-less setups; downloads of factoria carry it. `vscode`: copies the VS Code extension built into factoria (the script debugger, docs_read {"name":"debugging"}) to ~/.vscode/extensions/oxtailgames.factoria-<version>/ and to VS Code Insiders, VSCodium and Cursor when they exist, records the path of this factoria next to it and removes older versions; nothing is downloaded, so it is fast and safe to run without asking. `ffmpeg`: the static ffmpeg 6.0 build of github.com/eugeneware/ffmpeg-static (GPL, with libx264 and AAC; 19-28 MB depending on the computer) into $FACTORIA_HOME/tools/ffmpeg/<release>/, so `factoria run --record-video trailer.mp4` works without installing ffmpeg by hand; skipped when an ffmpeg is already found. Every download is checked against the publisher's checksum (error code `checksum_mismatch` installs nothing). Other error codes: network, cancelled, unsupported, invalid_argument, failed; the data of the error holds the steps done so far. Example: {"component":"android","acceptLicenses":true}.

| Argument | Type | Required | Description |
|---|---|---|---|
| `component` | string ["android","players","webplayer","cmake","xcode","appimage","shaders","vscode","ffmpeg"] | yes | What to install: android (JDK + Android SDK), players (other platforms' factoria_player + mobile libraries), webplayer (builds the web player from the engine checkout), cmake (iOS export), xcode (guidance only), appimage (appimagetool + runtime for the Linux AppImage export; Linux x86_64 only), shaders (sokol-shdc, compiles custom materials), vscode (the script debugger extension for VS Code, Insiders, VSCodium and Cursor), ffmpeg (turns --record-video recordings into .mp4). |
| `acceptLicenses` | boolean | no | android: the user has read the Android SDK license (setup.status components[].licenses) and agreed to it. Without it the install refuses with license_required. Never set it without asking the user. Default false. |
| `platforms` | array | no | players: which players to install (default: every desktop OS but this one, plus the mobile libraries when this factoria has none next to it). "web" installs the web export's player (factoria_player.js + .wasm); every download carries it next to factoria, so it is only fetched when asked for. |
| `force` | boolean | no | android, cmake, players, webplayer, ffmpeg: install again even when it is found (a JDK or CMake that is already there is used otherwise). Default false. |

## `setup.status`

Since 0.1.4.

Check what this computer has for exporting: the Android JDK and SDK, the players of other platforms, CMake, Xcode, the AppImage tools, sokol-shdc, the VS Code debugger extension, ffmpeg.

Returns {home, host, components[]}; each component is {id, title, state, details, paths, problems[], installSizeMb, licenses[], canInstall}. Components: `android` (JDK + Android SDK for APK/AAB exports), `players` (the factoria_player of the other desktop OSes and the prebuilt Android/iOS libraries, from the GitHub release of this factoria's version), `webplayer` (the web player built from the engine checkout this factoria was built from, for a development build: installed when build/web-release/player holds one of this build; unsupported without the checkout) `cmake` (3.24+, for the iOS export on a Mac), `xcode` (macOS: status only, it cannot be installed by a program) and `appimage` (appimagetool and the AppImage runtime, Linux x86_64 only: what `project.export` {platform: linux, format: appimage} builds an AppImage with) `shaders` (sokol-shdc, the shader compiler of custom materials: $SOKOL_SHDC, the one next to factoria or the pinned one under home/tools/sokol-shdc/) `vscode` (the FactorIA debugger extension in ~/.vscode/extensions and the other VS Code based editors' folders: installed when this factoria's version is there; docs_read {"name":"debugging"}) and `ffmpeg` (what `factoria run --record-video trailer.mp4` converts its recording to H.264 + AAC with: $FACTORIA_FFMPEG, "publish": {"ffmpeg"} of export.json, PATH or the one under home/tools/ffmpeg/). state is installed | missing | partial | unsupported (nothing to do on this computer). problems[] says what is missing and how to fix it; `setup.install` fixes everything except Xcode. `licenses` (android only, only while the Android SDK license is not accepted yet) holds {id, title, text}: the full license the user must read and agree to before `setup.install` with acceptLicenses. The only network request is the fetch of that license text (fetchLicenses false skips it). Everything installed lives under `home` ($FACTORIA_HOME, default ~/.factoria). Details: docs_read {"name":"exporting"}. Example: {"component":"android"}.

| Argument | Type | Required | Description |
|---|---|---|---|
| `component` | string ["android","players","webplayer","cmake","xcode","appimage","shaders","vscode","ffmpeg"] | no | Only this component (default: all of them). |
| `fetchLicenses` | boolean | no | Download the Android SDK license text when the license is not accepted yet (a network request). false = skip it (a polling UI). Default true. |
