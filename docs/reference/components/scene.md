# Components: Scene

## SceneSettings

Scene-wide settings stored under "settings" in the scene file: lighting, fog, gravity and background music.

| Field | Type | Default | Description |
|---|---|---|---|
| `ambientLight` | color | `[0.25,0.25,0.3,1.0]` | Base light added to all lit 3D surfaces so shadows are not pitch black. It is also the base light of lit 2D visuals (Sprite.lit, Tilemap.lit): a lit sprite shows its texture multiplied by this colour plus the Light2D lights. Raise it to [1, 1, 1] and the lit sprites look unlit. |
| `gravity2D` | vec2 | `[0.0,-980.0]` | 2D gravity [x, y] in world units/s^2 (default 980 pixels/s^2 downwards). |
| `gravity3D` | vec3 | `[0.0,-9.81,0.0]` | 3D gravity [x, y, z] in m/s^2 (default 9.81 downwards). |
| `fogColor` | color | `[0.5,0.6,0.7,1.0]` | Color distant 3D objects fade to. |
| `fogDensity` | float | `0.0` | Fog thickness; 0 disables fog. Range 0.0..10.0. |
| `skyColor` | color | `[0.45,0.62,0.85,1.0]` | Top color of the 3D background gradient (used when a perspective camera clears). |
| `horizonColor` | color | `[0.8,0.85,0.9,1.0]` | Bottom color of the 3D background gradient. |
| `music` | asset (audio) | `""` | Looping background music asset path. Empty = none. Loading a scene stops every sound and the music, then starts this track again, even when the previous scene had the same one; music a script started with audio.music(path, {persist: true}) keeps playing through the load, and is not restarted when this is the same track. |
| `musicVolume` | float | `0.6` | Volume of the background music, 0..1. Range 0.0..1.0. |
| `lightScale` | float | `1.0` | Size of the Light2D light buffer as a fraction of the picture, 0.25 .. 1 (default 1: one light pixel per picture pixel). Lower values make lights cost less fill rate and look softer (the light is smoothed up to the picture); use 0.5 on mobile or the web when many lights are on screen. Only matters when a scene has lit visuals and Light2D lights. Range 0.25..1.0. (since 0.3.0) |
| `colorSpace` | enum: gamma \| linear | `"gamma"` | How lighting and blending are computed. gamma (default, what every project made before M71 uses, so old projects keep their exact look): on the sRGB-encoded values, with 8-bit targets. linear: in linear light. The colours you pick (tints, sprite and material colours, light colours, ambient, fog, sky, clear colour, particle colours) are still sRGB values and are converted for you; colour textures (sprites, albedo, emissive, particles) are read as sRGB and data textures (normal, metallic-roughness, masks) as plain numbers; lights add up and fade as they do in the world, and the result is encoded for the display. The frame is kept in RGBA16F (values above 1 survive), else R11G11B10 (no alpha), else 8 bits that hold linear light (SRGB8A8), else plain RGBA8 with banding in the darks. RGBA16F costs twice the memory of RGBA8. Switch it on deliberately: colours picked by eye in gamma space look different and a project needs a second look (docs/RENDERING.md, Color space). Switching at run time is allowed. render.supports {"feature": "linearColor"} says whether this build and GPU can. Values above 1 survive until the display: without exposure, tonemap or colour filter in a PostProcess they clip there and the HUD blends in linear light too; with one, the final pass tonemaps and encodes the picture once and the HUD is drawn after it in display colours. (since 0.31.0) |
| `hdrOutput` | enum: off \| auto | `"off"` | off (default): the picture is shown in the standard range. auto: use a high dynamic range display where the platform allows it (Windows scRGB or HDR10, macOS and iOS EDR); on any other display it is the standard range, with no error. Only the tonemap of a camera's PostProcess (exposure or tonemap on) goes above paper white, up to the display's headroom; the HUD, a camera without it and a colour-filtered frame stay at paper white. render.output says what the window shows and why; render.supports {"feature": "hdrOutput"} says whether the window's display could. (since 0.31.0) |
| `paperWhiteNits` | float | `200.0` | Only used with hdrOutput auto on an HDR display: the brightness of white (1.0) in nits (cd/m2), 80..1000. 200 is comfortable indoors, 400 and more suits a bright room; the display shows brighter highlights above it. Range 80.0..1000.0. (since 0.31.0) |
| `skyMaterial` | asset (material) | `""` | Project-relative path of a custom material of kind "sky" (a *.material.json), or "" (default) for the skyColor / horizonColor gradient. The material's sky() snippet receives the view direction, the direction of the sun (the scene's directional light of slot 0), the time and the colour the gradient would have drawn, so it can replace or tint it; it draws the background of a perspective camera, opaque. The reflections and the ambient light of the meshes keep following skyColor and horizonColor. `material.info` lists the material's params and `shader.compile` compiles it and reports errors with file:line; a material that does not compile (or is not of kind "sky") shows the gradient and logs why. Guide: docs/SHADERS.md (`factoria docs read shaders`, "Sky materials"). (since 0.32.0) |
| `skyMaterialParams` | json | `{}` | Values for the params and textures of skyMaterial, an object keyed by the name declared in the material file: numbers for float params, arrays for vectors and colors ([r, g, b, a]), project-relative paths for textures. Example: {"horizonGlow": [1, 0.4, 0.1, 1], "stars": "textures/stars.png"}. Unnamed params keep the material's defaults. Ignored while skyMaterial is empty. The editor's Scene settings panel shows one control per param of the material. (since 0.32.0) |
| `shadowCascades` | int | `1` | Cascades of the directional light's shadow map, 1..4: each covers a longer stretch from the camera, so shadows stay sharp near it. Each is fitted to its slice of the view and keeps its texels still while the camera moves (no shimmer). 1 (default) = a single map. A GPU without float32Targets draws no shadow (render.supports cascadedShadows; docs/rendering/RENDERING_LIGHTING.md). Range 1..4. (not released yet, on main after 0.32.0) |
| `shadowCascadeSplit` | float | `0.5` | Where the cascades split along shadowDistance, 0..1: 0 = evenly spaced, 1 = logarithmic (a lot of detail near the camera), 0.5 (default) between. Range 0.0..1.0. (not released yet, on main after 0.32.0) |
| `shadowCascadeBlend` | float | `0.1` | Fraction 0..0.5 of a cascade over which it blends into the next, hiding the seam. 0 = a hard seam. Range 0.0..0.5. (not released yet, on main after 0.32.0) |
| `shadowDistance` | float | `0.0` | How far from the camera, in metres, shadows are drawn. 0 (default) = the engine's own fit around the view (the camera's far plane, or what the casters need when that is shorter). A light's own shadowDistance overrides it. The cascades split this stretch. Range 0.0..100000.0. (not released yet, on main after 0.32.0) |
| `shadowAtlasSize` | int | `4096` | The most texels per side the shadow atlas that holds every shadow map may have, 512..8192 (4096 default; the GPU's own limit also applies). Only the part the maps need is allocated (R32F: four bytes a texel, 2048 x 2048 = 16 MB); when they do not fit, the maps shrink, then the least important is dropped, the same every frame. Range 512..8192. (not released yet, on main after 0.32.0) |
| `contactShadows` | bool | `false` | Short screen-space shadow rays toward the light that add fine shadows where objects touch. Needs a GPU that can sample the depth (render.supports contactShadows). No effect yet: M73.2 brings it. (not released yet, on main after 0.32.0) |
| `environmentMap` | asset (texture) | `""` | An HDR image (.hdr, equirectangular) of the surroundings: it is the sky and lights and reflects in every surface. Empty (default) = the sky material or the gradient. No effect yet: M73.3 brings it. (not released yet, on main after 0.32.0) |
| `environmentIntensity` | float | `1.0` | Brightness multiplier of the environment map and the sky's image-based lighting, 0..100. No effect yet: M73.3 brings it. Range 0.0..100.0. (not released yet, on main after 0.32.0) |
| `environmentRotation` | float | `0.0` | Degrees the environment map is turned around the up axis. No effect yet: M73.3 brings it. Range -360.0..360.0. (not released yet, on main after 0.32.0) |
| `skyModel` | enum: gradient \| physical | `"gradient"` | gradient (default): the skyColor and horizonColor gradient. physical: a sun and an atmosphere computed from the directional light, with clouds. A skyMaterial or an environmentMap takes the place of both. No effect yet: M73.3 brings it. (not released yet, on main after 0.32.0) |
