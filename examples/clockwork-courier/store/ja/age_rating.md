# 年齢レーティングの回答 (Clockwork Courier 1.0.0)

各ストアの質問票には、次の内容で回答してください。このリポジトリで出荷される状態のゲームについての記述です。

| 質問 | 回答 |
|---|---|
| 暴力表現(デフォルメ、ファンタジー、写実) | なし。番犬がロボットを追いかけてチェックポイントに戻すだけで、誰も傷つかず、描写もありません。 |
| 流血、残酷表現、ホラー | なし。 |
| 性的表現、ヌード | なし。 |
| 汚い言葉、下品なユーモア | なし。 |
| 飲酒、喫煙、薬物 | なし。 |
| 疑似ギャンブル、ガチャ、ランダムな有料報酬 | なし。ペイントの色は固定価格で直接購入し、ランダム要素はありません。 |
| 懸賞、現金の賞品 | なし。 |
| ユーザー生成コンテンツ、チャット、ソーシャル機能 | なし。ランキングはプラットフォームのサービス(Game Center / Play Games)による自分のスコアと順位表で、自由入力のテキストはありません。 |
| 制限のないWebアクセス | なし。 |
| 位置情報の共有 | なし。 |
| アプリ内課金 | あり: 広告オフ(非消耗型)、銅色ペイントとネオンペイント(非消耗型)、オイル缶の応援(消耗型)。 |
| 広告 | 出荷版には、任意の「時間を追加」報酬型広告のスタブしかありません。実際の広告ネットワークをつなぐ場合は、そのネットワークについて回答し、privacy.md も参照してください。 |
| 医療・健康に関する表現 | なし。 |
| 子ども向け / ファミリープログラム | 子ども向けではありません。子どもに不適切な内容はありませんが、広告ネットワークと課金を専門家が確認するまで、子ども向け・ファミリーにはチェックしないでください。 |

想定される結果: App Store 4+、Google Play (IARC) 全年齢 / PEGI 3 / USK 0、ESRB E。最終的なレーティングは各ストアが算出するので、各質問票で確認してください。この表は回答内容の目安です。
