# Respuestas del cuestionario de clasificación por edades (Clockwork Courier 1.0.0)

Contesta el cuestionario de cada tienda con estos datos. Describen el juego tal como se entrega en este repositorio.

| Pregunta | Respuesta |
|---|---|
| Violencia (de dibujos, fantasía, realista) | Ninguna. Los perros guardianes persiguen al robot y lo devuelven a un control; nadie sale herido y no se muestra nada. |
| Sangre, escenas truculentas, terror | Ninguno. |
| Contenido sexual, desnudos | Ninguno. |
| Lenguaje soez, humor grosero | Ninguno. |
| Alcohol, tabaco, drogas | Ninguno. |
| Apuestas simuladas, cajas de botín, premios aleatorios de pago | Ninguno. Los colores de pintura se compran directamente a precio fijo; no hay azar. |
| Concursos, premios en dinero | Ninguno. |
| Contenido de usuarios, chat, funciones sociales | Ninguno. Las clasificaciones muestran la puntuación del propio jugador y una lista del servicio de la plataforma (Game Center / Play Games); no hay texto libre. |
| Acceso web sin restricciones | No. |
| Compartir ubicación | No. |
| Compras dentro de la aplicación | Sí: Quitar anuncios (no consumible), Pintura cobre y Pintura neón (no consumibles), Lata de aceite como propina (consumible). |
| Anuncios | La versión entregada solo tiene un sustituto para la oferta opcional de "más tiempo" con anuncio. Si conectas una red publicitaria real, contesta por esa red y mira privacy.md. |
| Afirmaciones médicas o de bienestar | Ninguna. |
| Hecho para niños / Programa Familias | No está dirigido a niños. Nada en él les es inadecuado, pero no marques Niños/Familias sin que un abogado revise la red publicitaria y las compras. |

Resultado esperado: App Store 4+, Google Play (IARC) Para todos / PEGI 3 / USK 0, ESRB E. Confírmalo en cada cuestionario: las tiendas calculan la clasificación final; esta tabla solo dice qué contestar.
